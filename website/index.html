HOW PALM SCALES

Vertical home · horizontal places

Scale is not “more threads and hope.” It is two axes that must stay honest together — and one law that ties them: there is no place like home.

Business stays on Behavior Trees. Organism topology is a different care. Same genome at every node — laptop all_in_one, cloud center, device realm, recursive server.

VERTICAL

Authority climbs the tree

Home points up. Truth home owns durable meaning. Projection mirrors it; when home is down, projection invalidates — work does not pretend. Organizations and realms are the same pattern, recursive: support that may have children of its kind. Mids propagate the center. Hop home for meaning — not mesh self-discovery as first law.

Children may have children. Ownership of meaning still belongs under the root palm.

HORIZONTAL

Bodies live in the place book

Workers, resources, containers, peer processes — spawn or adopt, health, readiness. Physical capacity spreads sideways across hosts and machines. Dependency down → do not drain that work yet. Multi-process is controlled life, not chaos.

Horizontal placement. Vertical ownership. Assembly makes the vertical real; workload keeps the horizontal honest.

RECURSIVE TREE (ILLUSTRATIVE)

logical depth · home up

Recursive supports. Places spread. Meaning still climbs home.

Phenotypes — same genome

  • Small — all-in-one on a device; company without a dedicated server if home stays online enough.
  • Cloud center — light root: decide, place, hear; optional tunnel broker.
  • On-device realm — phone or edge Palm that points home; sector may work offline until home returns.
  • Server realm — device big enough to parent; recursion, not a second product.

Traffic may feel flat · soul stays a tree

After the organism knows home, trusted paths (tunnels) let neighborhoods talk — app asks cloud for path to device, syncs, still has a home when truth is contested. Mesh feel. Tree law. No product copy — Palm’s own reach after assembly.

Install & doctor

pip install "palmengine[cli]"
palm version --full
palm doctor
palm status
palm repl

Library host

from palm.app import ApplicationHost, DeploymentProfile

with ApplicationHost(
    profile=DeploymentProfile.all_in_one()
) as host:
    job = host.submit_flow("onboard")
    print(job.status)
