# Orchestrating theme slices

The parent stays thin. Subagents munch the tree and implement. Sequential. Same workspace (`isolation: none`).

José decides floor, names, ADR accept, and exit. Package stamp stays until he says otherwise. Do not push unless he asks.

Read `STATUS.md` + the open VISION residual. Do not load the implementation into the parent.

## Sequence

1. **Plan** — name remaining slices from residual + leftover duck-typing. Docs theater is last.
2. **Scout (optional)** — explore subagent for leftovers. Do **not** ask “compost vs must stay.” That lets the scout defend `getattr`/`isinstance` as architecture.
3. **Verify soup** — parent greps `isinstance(` / `getattr(` on the theme files. Duck-walk of handles, engines, rows, or bind is an invert slice. Trust grep over a scout that said “none.”
4. **One slice at a time** — `general-purpose`, model `grok-4.5` unless José names another. Wait until it finishes. Then the next.
5. **After each invert** — grep those files again. If soup remains on the path, another slice. Payload/intent-boundary coercion may stay **named**.
6. **Docs last** — STATUS / VISION as-built / CHANGELOG Unreleased / PALM pointer. Theme stays open. ADR stays Proposed until José exits.
7. **Name lock / exit** — spawn a docs subagent. Parent does not edit those files.

## Implementer prompt (keep short)

- Intent in one line. Agency on how. Tests first. Commit locally when green. Do not push.
- Stamp / theme open / ADR Proposed / names not locked unless José already locked.
- Out of slice: later seeds, repo-wide ruff compost, docs theater beyond STATUS this-slice + VISION as-built one-liner + CHANGELOG one line.
- Stop and report if the next step is a workaround `if`.
- `uv run pytest` for slice tests. Point at `src/palm/AGENTS.md` §1.1 when the slice is an invert.

Do not micromanage the patch. Do not implement in the parent.

## Common failures

| Excuse | Reality |
|--------|---------|
| “Handles/overlay/admission must stay, so no slice” | Those homes can stay **named**. Duck-typing them is still unpaid. |
| “I’ll just edit it; the slice is small” | Parent context is the cost. Spawn. |
| “Scout said none” | Grep the theme files. |
| “Parallel the slices” | They share the tree. Sequential. |
